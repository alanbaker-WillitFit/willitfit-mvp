# RC3 Change Log

## Unreleased — RC3.0

- Established the certified RC2.59 Git baseline and RC3 feature branch.
- Added architecture, route, component, decision, issue and implementation registers.
- Centralised governed Tailwind design values and introduced runtime token definitions while retaining the locked RC2.37 palette.
- Unified the checker, allowance, result and next steps in one stateful Decision Module without changing calculation logic.
- Corrected mobile content order so supporting product recommendations follow the Decision Module before general knowledge content.
- Replaced the global navigation with the seven governed RC3 destinations on desktop and mobile.
- Added predictive, typo-tolerant discovery across airline and knowledge results with ranking tests.
- Added reusable breadcrumbs plus privacy, accessibility and legal pages linked from the trust-focused footer.
- Removed application-level colour literals, consolidating palette, surfaces, illustration colours and motion under governed tokens.
- Documented the reusable RC3 visual primitives and their supported states.
- Added skip navigation, explicit FAQ relationships, dropdown focus recovery and a keyboard-operable airline combobox.
- Added semantic accessibility regression contracts and the RC3 accessibility report.
- Integrated WillItFly RC0.4 as an optional offline-only static Lab experience with no core bundle dependency.
- Removed the proven-unreachable registration chain and added automated Lab isolation/privacy contracts.
- Corrected the four Lighthouse-proven colour-contrast defects using governed design tokens.
- Kept metadata in the document head for universal crawler compatibility and declared the existing brand mark as the site icon.
- Added controlled performance evidence and retained Linux/WSL OpenNext certification as an explicit release gate.
- Added consolidated QA, automated test evidence, captured mobile frames and the Product Owner UAT checklist.
- Versioned the release candidate as 3.0.0 and added deployment, rollback, monitoring and production-readiness controls.
